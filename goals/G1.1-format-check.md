# G1.1 書式の検査

> ゴール文書が G1 の書式に従っているかを機械で検査し、違反は AI のループの中で直す。

## 意図

G1 の書式は人の注意力を守るためにある。守られているかを人が目で確かめるのでは本末転倒なので、機械で検査する。
書式の違反は設計・実装レベルの問題なので、人には上げずに AI が直す（J1）。

## 具体例

- E1 `[機械]` G1.E1〜E6 に反するゴール文書があると、どの文書がどの具体例に反しているかを示して失敗する
- E2 `[機械]` 違反がなければ成功する
- E3 `[機械]` AI がゴール文書を編集すると直後に検査が走り、違反があれば AI に伝わる。人には通知されない
- E4 `[機械]` AI が一度直そうとしても違反が残る場合は、人に上申される（G0「収束しない」）

---

## AI 層

> ここから下は AI 向けの記録と根拠。人は根拠を確かめたいときだけ読めばよい。

### 設計

- 検査は `tools/check-goals.mjs`。Node.js の標準機能だけで書き、依存パッケージは使わない
- 実行方法は `npm run check`。違反があれば終了コード1で終わる
- Claude Code のフック（`.claude/settings.json`）で2か所から実行する
  - PostToolUse（Edit・Write）：`goals/` のファイルが編集されるたびに `--hook` 付きで実行する
  - Stop：Bash などフックを通らない編集も拾うため、作業の終わりに `--stop` 付きで全件を検査する
  - 違反は終了コード2で AI に返す。Stop で2回続けて違反が残ったら、止めずに人へ通知する（E4）
- 検査そのものが失敗した場合（入力の JSON が壊れている、ファイルが読めないなど）も、成功扱いにせず AI に返す
- テストは `npm test`（Node.js 標準のテストランナー。行カバレッジ80%以上）

検査項目と G1 の具体例の対応：

| 検査 | 対応 |
|---|---|
| frontmatter の必須項目、id とファイル名の一致、status の値、parent の存在、id の重複 | G1.E1 |
| 境界の見出し `## AI 層` | G1.E2 |
| 人間層の行数（判断待ちを除いて40行以内） | G1.E3 |
| 判断待ちの各項目に、推奨・自明な案・取り消し | G1.E4 |
| 判例の「上申」列にある Q が、判断待ちに残っていない | G1.E5 |
| J の重複、判断待ちの Q の重複、同じ Q からの複数の判例 | G1.E6 |
| 達成・中止のゴールに、それを決めた判例があるか | G1.E10 |
| ファイル名、題名・要約・意図・具体例の有無、判断待ちの置き方（1つだけ・人間層に・Q の項目だけ）、判例の列数と上申列の書き方 | G1 の書式の定義 |

コードブロックの中は、行数には数えるが、見出しや表としては読まない。

### 未対応

- G1.E5 は「判例に移ったのに、判断待ちに残っている」ことだけを検出する。判例に移さずに判断待ちから消した場合は検出できない。検出には git の履歴を見る必要があるため、G6（判例の記録と適用）で扱う
- Bash で編集した場合、E3 の「直後」ではなく作業の終わり（Stop）で検査される

### 経緯

- 2026-10-12：実装とは独立した AI のレビューで8件の指摘（判断待ちの書き方を変えると検査をすり抜ける、検査自体の失敗が成功扱いになる、Bash での編集が検査されない、など）。すべて再現テストを書いてから修正した
- 2026-10-12：同じレビュー担当の再確認で、7件は解消、1件（Bash での編集）は一部解消（上の未対応を参照）。修正で生じた誤検出3件（`### Q3：問い` を違反にする、異なる記号のフェンスで閉じる、上申列の自由記述から Q を拾う）も、再現テストを書いてから修正した。上申列の書き方は G1 の書式の定義に明記した
- 2026-10-12：新しいセッション（`claude -p`）で、フックが実際に動くことを確認した
  - E3：編集の直後に PostToolUse フックが終了コード2で指摘を返した（デバッグログで確認）
  - E4：違反を直さずに2回止まろうとすると、Stop フックが人への通知に切り替わった
  - 発見：指摘を受けた AI が、status を「完了」から元の「進行中」に戻さず、「達成」に書き換えて検査を通した。書式は正しいが意味は誤り。G0 の落とし穴「評価のハック」の実例として、G1 の Q10 で上申した（J18 で決定し、G1.E10 として検査に追加）

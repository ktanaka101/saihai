# saihai（采配）

[English](README.md) | 日本語

人は采配を振るだけ。

saihai は、人が AI へ委任し、機動的に協調するための考え方と道具です。

- **委任**：人が決めるのは、何のために・どちらへ・どの程度よくしたいか（意図）と、越えない線（制約）と、止まって聞いてほしい条件（報告条件）だけ。具体的な目標と、やり方と、確かめ方は AI が立てる
- **機動的**：状況が変わっても、AI は人を待たずに、意図から判断して進み続ける。止まって聞くのは、取り返しがつかないときと、人の答えで結果が変わるときだけ
- **協調**：意図を共有したうえで、縦と横で知らせ合う。縦（人と AI）では、AI が着手前に理解を返し、終わりに決めたことと確かめていないことを報告する。横（AI 同士）では、同じものを分け合うセッションどうしが、使えなくなる変更の始めと終わりを知らせ合い、ぶつかったときだけ人が決める

いまは、委任と縦の協調を受け持つ「ゴールプロンプト」（AI に仕事を任せるときに渡す文書）の書き方から始めています。原則は **目的は短く固め、やり方は任せる** です。

- [ゴールプロンプトの書き方](guide.md)：原則、書く項目、悪い例と良い例、よくある失敗、ほかのセッションと同じものを使うとき
- [雛形](template.md)：コピーして埋める
- goal-draft スキル（Claude Code のプラグイン）：一言の方向から、AI が下調べをして草案を書き、決めることだけを聞いてくる

考え方の土台は、委任型指揮（Auftragstaktik）です。AI とは人のような信頼関係を積めないので、その代わりに、意図を推測できる情報（理由の付いた制約・指針・前提と、確度の付いた見立て）と、正当な出口（通せないときは、近道をせずに止まって報告してよい）を渡します。詳しくは[ガイド](guide.md)にあります。

## 使い方

### 雛形をコピーする

[template.md](template.md) をコピーして埋め、実装する AI に「このファイルを読んで、『実装する AI へ』に従って進めて」と頼みます。ただの Markdown なので、どのコーディングエージェントにも渡せます。

### Claude Code で、AI と一緒に書く

使いたいプロジェクトにだけ、プラグインを入れます。そのプロジェクトのフォルダで:

```bash
claude plugin marketplace add ktanaka101/saihai
```

```bash
claude plugin install saihai@saihai --scope local
```

`--scope local` にすると、自分の、そのプロジェクトだけで有効になります（`.claude/settings.local.json` に記録されます）。チームで使うなら `--scope project`、すべてのプロジェクトで使うなら `--scope user` です。

あとは、どちらへどの程度よくしたいかを一言で伝えます。

> 毎月の支出の集計に手間がかかっていて、使いすぎに気づくのが月末になってしまう。週の途中には気づけるようにしたい。ゴールにして

AI が下調べをして草案を書き（`goals/` に置きます）、決めることだけを選択肢つきで聞いてきます。答え終わったら「実装して」と頼みます。

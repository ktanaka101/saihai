# 受信箱（参謀の手順）

あなたは参謀です。人にコマンドを打たせません。受信箱の中身を質問の形にして会話の中で聞き、答えはあなたが記録します。

## 手順

1. **受信箱を開く**：`node bin/saihai.mjs inbox` を実行して読む
   - 何もなければ「いま判断すべきことはありません」と伝え、ゴールの段階を1行で添えて終える
2. **判断待ちを聞く**（AskUserQuestion。1回で4件まで）
   - 問いは判断待ちの題をそのまま使う。推奨の選択肢を先頭に置き、ラベルの末尾に「（推奨）」を付ける。説明には推奨の理由を短く書く
   - 自明な案も選択肢に入れる。人はほかの答えを自由に書ける
   - 答えを記録する：推奨なら `node bin/saihai.mjs answer Q{番号} 推奨 --asked`、自明な案なら `node bin/saihai.mjs answer Q{番号} 自明な案 --asked`、自由な答えなら `node bin/saihai.mjs answer Q{番号} --text "答え" --asked`
   - 「まだ決めない」と言われたら、記録せずに判断待ちのまま残す
3. **事後確認を聞く**（AI が逸脱・指摘したり、判定や数字を動かしたりしたもの）
   - 各項目を1行ずつ示し、「すべて確認済みにする（推奨）」「一部に異議がある」「まだ見ない」を聞く
   - 確認済みなら `node bin/saihai.mjs confirm D{番号} D{番号} …`。異議があれば、どれに何の異議かを聞き、その判断を見直す（見直した内容は判断ログに残す）
   - 事後確認を AI が自分で確認済みにしない
4. **仮説の外れ・矛盾**があれば、interpret スキルの手順で事後検証を行い、次の判断を判断待ちにしてから、もう一度この手順で聞く
5. **伝える**：記録したこと（どの判断待ちが判例になったか、何を確認済みにしたか）と、残っているものを短く伝える

## 守ること

- 人に saihai のコマンドを打たせない。コマンドはあなたが実行する
- 人の答えを推奨に寄せて言い換えない。答えたとおりに記録する
